# Facial Temperature Analysis

This repository contains the R code used for data preparation, statistical analysis, and figure/table generation for my Bachelor thesis.

## Scripts

- `01_prepare_temperature.R` – preparation of thermal imaging data
- `02_prepare_movement.R` – preparation of movement data
- `03_prepare_questionnaire_data.R` – preparation of questionnaire data
- `04_merge_behaviour_data.R` – merging of behavioural datasets
- `05_merge_temperature_data.R` – merging of behavioural and temperature data
- `06_descriptive_statistics.R` – descriptive analyses and descriptive table
- `07_analysis.R` – main statistical analyses
- `08_model_inference.R` – model inference, robustness analyses, and figures
- `ICC_FLIR.R` – inter-rater reliability analysis for thermal coding

## Data availability

The data used in this thesis are not publicly available in this repository. Access to the data may be requested from Raphaela Heesen.
